# Real-phone test checklist

Test on a real Android phone (ideally a low-end one) and, if you can, an iPhone. Install it as an app from the live GitHub Pages link, not just in the browser tab. Tick each line.

## Install and offline
- [ ] Install works (Android: Install app. iPhone: Add to Home Screen) and the icon looks right.
- [ ] Open once with internet, then switch on airplane mode and reopen. The app opens.
- [ ] Add a piece with **Cut by hand** while offline. It works.
- [ ] With internet, do one **automatic cutout** (downloads the model). Then go offline and do another. It still works.
- [ ] After a new deploy, close and reopen the app. The new version number shows in Profile > Storage and about.

## Back button (Android)
- [ ] Open a section, then Back. You return to Wardrobe, with no filter sheet showing.
- [ ] Open a piece, then Edit, then Back twice. Edit closes first, then the piece.
- [ ] Open the filter sheet, press Back. It closes.
- [ ] From Planner or Profile, Back goes to Home. On Home, Back leaves the app.

## Adding and editing
- [ ] Add one piece with front and back photos, then add a few at once.
- [ ] Edit a piece, tap **Touch up front**, erase some background, Save. The new photo shows in the grid.
- [ ] Move a piece to **Common** in Edit.
- [ ] Add a price, wear the piece, check the cost per wear.

## Everyday features
- [ ] Mark a piece for the laundry. It disappears from Today's pick and Mix & Match.
- [ ] Save a favorite outfit, then use it on another day.
- [ ] Build a 3-day packing list and tick pieces off.
- [ ] Mark a piece Donate, then Sold with a price, and find it in Let go > History.
- [ ] Insights shows Wardrobe check and Value.
- [ ] Turn on Weather, search your city, see the forecast on Home and Planner.

## New in 1.1
- [ ] Profile > Look > Appearance > AMOLED: the background is pure black and cutouts have a soft glow behind them. Close and reopen the app: no flash of another theme.
- [ ] The sun/moon button switches between light and your last dark style (Dark or AMOLED).
- [ ] Wardrobe > Rail: pieces hang on rails by category. Tap one: it swings and opens. Select mode shows the normal grid.
- [ ] Open a piece: "Goes well with" shows colours and matching pieces from your wardrobe.
- [ ] Mix & Match shows a "Colours: ..." line.
- [ ] Insights > Wardrobe Wrapped: the card draws, Share opens your share sheet, Save puts a PNG in Downloads. No innerwear appears.

## Privacy, backup, speed
- [ ] Set a PIN, turn on the hidden Innerwear section, close and reopen. The lock appears.
- [ ] Save a backup file, delete everything, restore the backup. Everything is back.
- [ ] Try Speed: Fast, Balanced, Full. Scrolling a long grid should feel smooth on Fast.
- [ ] Dark mode and Auto look right. Try two theme packs.

## Look for
Text cut off, buttons hidden behind the tab bar or keyboard, photos that stay blurry, anything that feels slow. Note the phone model and what you pressed.
