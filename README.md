# Wardo

Your wardrobe, in your pocket. Photograph your clothes, keep clean cutouts, and never forget what you own.

Free, private, and runs entirely on your phone. No account, no server.

## Status

v0.12.0: optional weather suggestions, packing lists, wardrobe check (gaps and duplicates), Donate and Sell. v0.11.0: laundry status, price and cost per wear, favorite outfits and Mix & Match. v0.10.1: fixes (filter sheet no longer stuck open, Android Back button steps back through screens) and a faster app with Settings for animations, blur, theme packs, accent colour and your name. Before that, v0.10.0: PIN lock and hidden Innerwear, add many pieces at once, cutout helpers. Before that, v0.9.0: new Closetly-style look (Home, cream and teal), offline install (service worker). Before that, v0.8.1: add items with automatic or by-hand cutout, touch-up, tags, search and filters, folders, wear tracking, forgotten clothes, outfit planner calendar, daily suggestion, backup and restore. All data stays on the device.

## Run locally

```bash
npm install
npm run dev
```
