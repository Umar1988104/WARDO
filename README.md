# Wardo

Your wardrobe, in your pocket. Photograph your clothes, keep clean cutouts, and never forget what you own.

Free, private, and runs entirely on your phone. No account, no server.

## Status

v0.1.1: app shell with refreshed design and quick theme toggle (iOS-style glass design, tabs, dark mode). Wardrobe features arrive in the next versions.

## Run locally

```bash
npm install
npm run dev
```
